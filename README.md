# Socket.IO 实时通信 Demo 💬

> 基于 Node.js 与 Socket.IO 的即时全双工 WebSocket 多人实时聊天应用。

[![Socket.IO](https://img.shields.io/badge/Socket.IO-Realtime-black?style=flat-square&logo=socketdotio)](https://socket.io/)
[![Node.js](https://img.shields.io/badge/Node.js->=12-green?style=flat-square&logo=nodedotjs)](https://nodejs.org/)
[![Archive](https://img.shields.io/badge/Status-Historical%20Archive-lightgrey?style=flat-square)](https://github.com/qqlcx5)

---

> ⚠️ **历史归档项目**：本项目用于理解网络全双工双向通信与广播协议机制。

## 📖 核心实现

- 多人在线房间管理与客户端上线/离线事件广播
- 消息即时推送到全体在线客户端（广播模型）
- 极简 HTML 客户端与服务端双向数据流演示

---

## 🚀 运行

```bash
yarn install
node server.js
```
打开浏览器访问 `http://localhost:3000` 即可体验双窗口实时互发聊天。
